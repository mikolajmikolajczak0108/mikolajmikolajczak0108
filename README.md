## Gest zamiast myszy

Co się stanie, gdy zwykła kamera internetowa zastąpi mysz? Rozpoznanie dłoni to początek. Prawdziwe wyzwanie to spokojny ruch kursora i kliknięcie, które nie przesuwa celu.

W **Gesture Cursor Control** jedna dłoń wskazuje, druga klika, a wygładzanie EMA ogranicza drgania. To prototyp edukacyjny realizowany z uczniami Step IT Academy — okazja do połączenia computer vision, stanu aplikacji i projektowania interakcji.

**Python · OpenCV · MediaPipe · Tkinter**

[Zobacz kod i instrukcję uruchomienia →](https://github.com/mikolajmikolajczak0108/gesture-cursor-control)

## Instrukcje, które można sprawdzić

„Zrób audyt” nie mówi jeszcze, co należy zbadać i jak ocenić odpowiedź. W **Open Prompts** zapisuję zadania dla AI z kontekstem, granicami, oczekiwanym rezultatem i kryteriami odbioru.

To otwarty zbiór instrukcji do code review, threat modelingu, DevSecOps, UI/UX, SEO i stron z grafiką 3D. Zwykły Markdown pozwala je przeczytać, dostosować i wersjonować razem z projektem.

**AI workflows · Application security · DevSecOps · Markdown**
